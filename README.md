# 🛍️ React E-Commerce Store

A modern and responsive **React E-Commerce Store** built to practice core React concepts and frontend development. This project demonstrates product listing, routing, shopping cart management, search functionality, and state management using the Context API.

---

## 🚀 Features

* 🛒 Add to Cart functionality
* ➕ Increase product quantity
* ➖ Remove products from cart
* 🗑️ Clear entire cart
* 🔍 Search products by name
* 📂 Category filter *(currently under development)*
* 📄 Product Details page
* 🔄 Client-side routing with React Router
* 📱 Fully responsive UI
* ⚡ Fast development with Vite
* 🎨 Modern UI using Tailwind CSS

---
